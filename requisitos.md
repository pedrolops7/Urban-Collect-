# Levantamento de Requisitos

## Requisitos Funcionais (RF)
* **RF01:** O sistema deve permitir que os motoristas visualizem mapas em tempo real.
* **RF02:** O sistema deve alertar o motorista quando um contêiner atingir o nível crítico de capacidade (ex: 95%).
* **RF03:** O sistema deve recalcular as rotas dinamicamente com base nos alertas dos sensores.

## Requisitos Não Funcionais (RNF)
* **RNF01:** O banco de dados deve suportar sincronização em tempo real (Firebase).
* **RNF02:** Os sensores IoT devem possuir blindagem resistente a vandalismo e intempéries climáticas.
* **RNF03:** A interface mobile deve ser responsiva e de fácil leitura para o motorista em movimento.
